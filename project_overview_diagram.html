AI-Analyst-Alfa — цикл проверки гипотез

Настольная часть цикла ≈ 3 часа; полная валидация с живыми интервью — 2–4 недели. Сплошное кольцо — ход цикла, пунктирные спицы — запись результатов в канонический лог решений; вердикты меняют только живые данные. Ниже — отгруженные продукты и статус пяти ролевых треков.

Отгружено — 2 продукта

  • DL-0 · RegExp-генератор для сценаристов чат-ботов — ~30% времени спринта возвращено
  • DL-1 · Text→SQL мультиагент для дата-аналитиков — ~20% капасити команды
  • Оба — паттерн «аугментировать, не заменять»

Роли-кандидаты (evidence × access)

  • #1 Аналитики данных — 3 живых интервью; build-фаза DL-19/18/17
  • #2 Сценаристы чат-ботов — синтетика + реестр кейсов; живых интервью нет
  • #3 Продуктовые дизайнеры — secondhand через разработчика
  • #4 Продакт-менеджеры — 4 живых интервью, DL-21…31
  • Новый трек: Бизнес-аналитик — 2 синтетики, первое живое интервью на днях

Пульс проекта

  • 32 цикла записаны в канонический лог (DL-0…DL-31)
  • Лидер по ICE — H-PM-19 (оценка эффекта, 252)
  • Кросс-паттерн: боль в интерпретации требований, не в исполнении
  • Валидация гипотезы: 2–4 недели, синтетика → 3–5 живых интервью
